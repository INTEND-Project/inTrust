# Model Robustness Assessment

Use this skill when the intent asks whether a machine learning model is robust
against input perturbations, adversarial noise, sensor variation, or operational
anomalies.

## Inputs

Expected inputs include a model reference, evaluation data reference, and any
perturbation policy or robustness criteria included in the intent.

## Execution

No executable tool is registered yet. If this skill is selected, explain the
missing implementation and return a TM Forum aligned `FAILED` or
`PENDING_IMPLEMENTATION` report with the required parameters for follow-up.

## Output

Return a structured report that states the robustness assessment could not yet
be executed automatically and identifies the missing implementation.
