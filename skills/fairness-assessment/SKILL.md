# Model Fairness Assessment

Use this skill when the intent asks whether a machine learning model is biased
against specific groups, protected attributes, input categories, or fairness
criteria.

## Inputs

Expected inputs include a model reference, dataset reference, protected or
sensitive attributes, and the fairness metric or policy to evaluate.
